Attribution for jetbrainsmono-nerd-v1.woff2
===========================================

This file is a size-only subset of:

    JetBrainsMonoNerdFontMono-Regular.ttf
    from Nerd Fonts release v3.4.0
    https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.4.0

No glyph outlines were altered. The subset keeps ASCII + Latin-1 plus 14
individually selected icon codepoints; see tools/fonts/icons.txt in the
qbitflow repository for the exact list and tools/fonts/subset-font.sh for
the command that produced it.
